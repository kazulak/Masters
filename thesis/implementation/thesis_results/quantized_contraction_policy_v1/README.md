# Quantized Contraction Policy v1 Results

This is the deterministic CPU-only characterization of
`complex_int8_shared_scale_v1` generated by
`scripts/analyze_quantized_contractions.py`.

The recorded suite uses the existing greedy path for Bell2, Stress4, GHZ18,
HS18, and Stress18. `quantization_nodes.csv` separates isolated local-node
sensitivity from cumulative error propagation. `quantization_circuits.csv`
contains final phase-sensitive comparisons against the same-DAG float32 route
and the existing complex128 reference. `quantization_summary.json` retains the
policy, execution, and claim boundaries.

The results are accuracy-unqualified. Logical encoded byte counts are not
measured H2D traffic, MRAM traffic, or a physical transfer reduction. No UPMEM
hardware, SDK simulator, native DPU binary, or physical benchmark produced
this snapshot.
