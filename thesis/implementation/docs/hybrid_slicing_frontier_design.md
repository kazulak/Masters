# Historical Hybrid Slicing Notes

The former CPU frontier and hybrid slicing routes are retired from the active
Phase B command, Make, pytest, and CI surfaces. Their route labels and
normalized records remain readable for historical reports and snapshots.

Current CPU tensor-network claims use the exact path/circuit contracts and the
active Quimb baseline. Historical frontier or hybrid rows are diagnostic
artifacts only; they are not current parallel-execution or speedup evidence.
UPMEM users should use the strict generic-only simulator command or the manual
one-DPU MRAM-resident hardware route documented in the
[resident runbook](upmem_hardware_taskgraph_resident_runbook.md).
