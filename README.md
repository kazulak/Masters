# Masters

Repository for Master's-level university coursework and the Master's thesis work at
Poznań University of Technology, Computer Science — Distributed and Cloud Systems.

## Master's thesis

The thesis research is under:

```text
thesis/
```

The implementation studies exact tensor-network quantum-circuit simulation on UPMEM
Processing-in-Memory hardware, including physical execution, hierarchical parallelism,
numerical-policy experiments, and hardware-aware contraction-path optimization.

The implementation research phase is complete. Start with:

```text
thesis/README.md
```

The final accepted P6 cost-guided path result package is:

```text
thesis/implementation/thesis_results/upmem_cost_guided_path_v1/
```

The frozen scientific identities are documented inside the thesis subtree.

## Other repository material

Other top-level directories contain coursework, study material, and experiments retained
